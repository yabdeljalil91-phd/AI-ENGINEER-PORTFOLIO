# AI Engineer Portfolio

A responsive, dark-themed personal portfolio built with Angular standalone components.

## Requirements

- Node.js 22.22.3 or newer
- npm

## Run locally

```bash
npm install
npm start
```

Open http://localhost:4200.

## Production build

```bash
npm run build
```

The production output is generated in `dist/ai-engineer-portfolio/browser`.

## Personalize before publishing

1. Update the profile, email, social links, skills, experience and projects in `src/app/app.component.ts`.
2. Replace the sample project descriptions and GitHub/demo URLs with real links.
3. Add your CV as `public/assets/cv.pdf` (create the `assets` folder).
4. Replace the initials avatar with a portrait if desired.
5. Check all links and contact details on desktop and mobile.

## Deploy

Build with `npm run build`, then deploy the contents of `dist/ai-engineer-portfolio/browser` to a static hosting provider such as Netlify, Vercel or GitHub Pages.
